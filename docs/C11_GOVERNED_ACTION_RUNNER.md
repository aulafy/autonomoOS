# C11 GovernedActionRunner

`@agent-world/control-plane` provides the live action path. The host registers actions, executors and observers. An ActionIntent from a model or client cannot select an executor or mint authority. Admission resolves a canonical resource, checks the active C1 contract, C3 authority and resource leases, generic policy, C8 composition, C9 flow where required, C10 supervision, and C4 budget. It reserves budget and prepares a C6 EffectTransaction. The returned admission snapshot records versions and fences for audit.

`dispatchPrepared` accepts only a token previously issued by this runner. It rechecks live contract, authority, leases, resource generations, composition history, flow working set and release approval, reservation expiry, emergency stop and executor quarantine. The effect enters `dispatching` before the executor is invoked. Executor success leaves it dispatching until C5 observation confirms the postcondition. An uncertain outcome keeps the budget hold and queues C7 reconciliation. Pre-dispatch denial releases the reservation.

`TaskCompletionEvaluator` requires all specified effects to be committed, all contract acceptance criteria to map to accepted current observations, no unsettled effect, and no pending blocking approval. Exhausting a plan alone does not complete a task.

The M5 runtime routes `goto`, `say` and `demo.slow` through a host-owned demo adapter. The only `world.execute` call is inside its registered executor. It emits existing movement, speech and replay events. Unsupported or higher-risk actions are denied. The demo's in-process stores, grant source, observer and supervisor snapshot are scaffolding; they are not a durable production authority service. Speech confirmation reads an in-process event generated by the demo world, so it is weak evidence suitable only for the current low-risk demo. C12 must handle startup recovery and durable state separately.
